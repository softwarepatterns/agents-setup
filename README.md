# softwarepatterns/skills

Estate catalog of agent skills shared across machines and repos.

- **Estate-owned:** `skills/`
- **Vendored (upstream):** `vendor/skills/<github-owner>/` — see each owner's `README.md` for pins
- **Law for agents working on this repo:** `AGENTS.md` and `.agents/references/`

This repository does not apply its skill payloads to itself; consumers install
from here into their own `.agents/skills/` (or equivalent).
